# 04 — Školenie nováčikov

## Cieľ
Scenáre + kvíz na *vaše* zariadenie, aby nový operátor neskúšal všetko naživo na teba.

## Stav
Scaffold. Plný obsah neskôr; najprv 01 a 03, čiastočne 02 (stromy sa dajú znovu použiť ako otázky).

## MVP (neskôr)
- 10–20 scenárov v `scenarios/`
- Režim učenie / test
- Väzba na alarm tree (02) a denník (01)

## Otvorené otázky
1. Aké chyby robia nováčikovia najčastejšie?
2. Máte schémy/fotky panelov ktoré smú ísť do nástroja?
