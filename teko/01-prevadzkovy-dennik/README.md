# Prevádzkový denník (Excel)

Šablóna `dennik-kotly.xlsx` — listy Dennik / Ciselniky / Prehlad.

- Typ zariadenia → Zariadenie (dropdowny z Ciselniky)
- Typy udalostí: Nabeh, Odstaveny, Koniec sezony, Porucha, Oprava, Poznamka
- 4 žlté PRIKLAD riadky — pred ostrým používaním zmaž
- Zalomený text v stĺpcoch Dovod / Kratky popis / Poznamka

Plant predpisy a reálne denníky sem nepatria (ostávajú lokálne).
