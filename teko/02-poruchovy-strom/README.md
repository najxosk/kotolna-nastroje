# Poruchový strom

Otvor `poruchovy-strom.html` v prehliadači (súbory .css/.js musia byť vedľa).

- Režim chôdze: ÁNO/NIE, strom rastie, Späť / klik na minulý uzol
- Upravovať: stromy a uzly, localStorage
- Záloha: voliteľný JSON export/import (nie beh na zmene)

Ak starý cache: Upravovať → Záloha → Reset na demo.
