# TEKO — kotolňové nástroje

Pracovné drafty pre zmenu. Každý projekt má vlastnú zložku.

| Zložka | Čo |
|--------|----|
| `01-prevadzkovy-dennik` | Excel denník (nábehy, odstavenia, poruchy…) |
| `02-poruchovy-strom` | HTML rozhodovací strom |
| `03-optimalizacia-z-dat` | Import dát / draft optimalizácie |
| `04-skolenie-novacikov` | Neskôr |

**Lokálne len:** plant predpisy (MPPP), reálne SCADA/CSV z práce, osobné denníky — nepatria do tohto repa.
