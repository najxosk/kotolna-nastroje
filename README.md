# Kotolňa nástroje

Praktické nástroje pre operátora kotlov / tepláreň. Každý projekt má vlastný priečinok.

| # | Projekt | Stav | Priorita |
|---|---------|------|----------|
| [01](01-prevadzkovy-dennik/) | Prevádzkový denník (hrubý log nábehov/odstavení) | návrh | vysoká |
| [02](02-alarm-decision-tree/) | Alarm decision tree (hlavne pre nováčikov) | návrh + demo | stredná |
| [03](03-optimalizacia-z-dat/) | Optimalizácia z hodinových dát (plyn/vzduch, voda/para, výkon) | návrh + sample | **najvyššia – smer ďalej** |
| [04](04-skolenie-novacikov/) | Školenie nováčikov | scaffold | neskôr |

## Zásady

- Offline / lokálne kde sa dá (kotolňa nemusí mať dobrý net).
- Žiadne ručné hodinové ťukanie do formulárov — dáta sa majú **importovať**.
- Plant-špecifické čísla vždy označiť ako *príklad*, kým ich nepotvrdí operátor.
